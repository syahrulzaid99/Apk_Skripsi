# AGENTS.md — Apk Skripsi

## Overview

Monorepo with two apps: a **Flutter mobile app** (`flutter_aqua/`) and an **Express backend** (`web_aqua/`). The root `package.json` only holds the `docx` dep for a thesis-appendix generator (`generate_lampiran.js`).

## Web Backend (`web_aqua/`)

- **Entrypoint**: `src/app.js`
- **Framework**: Express 5 + EJS with `express-ejs-layouts` (default layout: `views/layouts/base.ejs`)
- **Database**: Firebase Firestore via `firebase-admin` (initialized in `src/firebaseAdmin.js`)
- **Auth**: JWT — cookie (`__session`) for web pages, Bearer header for API (`/api/`). Middleware: `requireAuthApi`, `requireRole()` in `src/middleware/auth.js`
- **File uploads**: Multer → `uploads/products/` (read-only on Vercel; mkdir failure is non-fatal)
- **Dev**: `npm run dev` (nodemon, watches `src/app.js`)
- **Deploy**: Vercel (`vercel.json` uses `@vercel/node`, all traffic → `src/app.js`)
- **Environment**: `.env` at project root — must have `FIREBASE_PROJECT_ID`, `FIREBASE_CLIENT_EMAIL`, `FIREBASE_PRIVATE_KEY` (or `GOOGLE_APPLICATION_CREDENTIALS`). Also `JWT_SECRET`, `SESSION_COOKIE_NAME`, `CSRF_SECRET`.
- **Script**: `scripts/createUser.js` — seeds a user in Firestore. Run from `web_aqua/` after `.env` is set.
- **Tests**: none (`npm test` is a stub).

## Flutter App (`flutter_aqua/`)

- **Entrypoint**: `lib/main.dart`
- **Backend URL**: hardcoded `http://192.168.8.105:3000` in `lib/main.dart:12` — must be updated if the server IP changes.
- **Auth**: token stored in `SharedPreferences`, sent as `Authorization: Bearer` header.
- **Key packages**: `mobile_scanner` (barcode), `image_picker`, `http`, `shared_preferences`
- **Run on device**: `flutter run` (or `run_flutter.ps1` which also launches scrcpy for screen mirroring)
- **Lint**: `flutter_lints` (config: `analysis_options.yaml` → `package:flutter_lints/flutter.yaml`)
- **Icons**: generated by `flutter_launcher_icons` from `assets/logo.png`

## Root-level scripts

- `node generate_lampiran.js` — builds `Lampiran_Listing_Program.docx` from the listed source files.

## Gotchas

- The Flutter app hardcodes the server IP. Not configurable at runtime.
- web_aqua routes are all mounted at `"/"` — route ordering matters in `app.js`.
- Firebase Admin supports two init paths: ADC (`GOOGLE_APPLICATION_CREDENTIALS`) or 3 env vars. The `FIREBASE_PRIVATE_KEY` must have `\n` replaced with real newlines (handled in `firebaseAdmin.js:17`).
- Vercel deployment is serverless — don't rely on local filesystem writes (uploads folder creation failure is caught and logged as warning).
- No CI, no tests, no typechecking, no pre-commit hooks across the repo.
